# Energy Brain Layout Modes

## Philosophy

Layout switching belongs in Configuration,
not in the live runtime cockpit.

Reason:
- cleaner runtime UI
- less visual clutter
- more stable rendering
- operator-focused UX

## Modes

### Auto
Automatic device detection.

### Desktop
Mission control layout.

### Tablet
Control panel layout.

### Mobile
Operator companion layout.

## Runtime UI priorities

### Desktop
- Powerflow
- Timeline
- Forecasts
- Safety
- Planner details

### Tablet
- Simplified grid
- Large touch targets
- Reduced density

### Mobile
- Explainability first
- Compact powerflow
- Sticky runtime status
- Minimal metrics
