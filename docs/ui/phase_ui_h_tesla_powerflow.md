# Phase UI-H — Tesla Style Powerflow

## Goal

Modern animated EMS powerflow:
- centered energy hub
- animated flow lines
- rounded nodes
- minimal clutter
- Tesla-inspired visuals

## Features

- dynamic energy direction
- animated flow paths
- battery ring visualization
- export/import visibility
- responsive component support

## UX Philosophy

The operator should instantly understand:
- where energy comes from
- where it goes
- battery state
- import/export behavior

without reading large tables.

## Safety

Renderer-only phase:
- no HA writes
- no dispatch
- observer-safe
