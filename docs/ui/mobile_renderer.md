# Phase UI-C - Mobile Renderer

## Philosophy

Mobile layout is:
- explainability-first
- operator-focused
- minimal clutter
- glanceable

## Included sections

- Hero
- Compact powerflow
- Explainability
- Timeline cards
- Sticky statusbar

## Excluded intentionally

- Debug JSON
- Entity lists
- Large graphs
- Planner internals
- Developer diagnostics

## Safety

Renderer only.
No runtime logic changes.
